# Expert News Analyzer 📊

AI 驱动的投资新闻分析工具，自动获取新闻并生成多专家观点分析报告。

[English Version Below]

## 功能特点

- 📰 多源新闻聚合（中英文 RSS 源）
- 🤖 AI 专家分析（模拟 10+ 位投资名人观点）
- 📈 趋势预测信号
- 📱 微信/飞书/ Telegram 推送
- 🔄 定时自动运行

## 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/ryan168666/expert-news-analyzer.git
cd expert-news-analyzer

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置
cp config.yaml config.yaml.bak
# 编辑 config.yaml 填入你的 API Key

# 4. 运行
python3 analyzer_v2.2.py
```

## 配置说明

编辑 `config.yaml`:
- `api_key`: Zhipu API Key (glm-4 模型)
- `news_limit`: 获取新闻数量
- `min_score`: 最低评分过滤
- `output_dir`: 报告输出目录

## 专家自定义

在 `experts/` 目录添加自定义专家配置 YAML 文件。
